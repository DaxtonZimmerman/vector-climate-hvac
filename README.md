# Vector Climate

An interactive four-page HVAC portfolio with a system explorer and project planner.

**[Open the live website](https://daxtonzimmerman.github.io/vector-climate-hvac/)**

Designed and developed by Daxton Zimmerman as an independent portfolio concept. The brand is fictional; this is not commissioned client work. Photography is AI-generated.

## Run and edit

The website is in `dist/`. Open `dist/index.html`, or serve `dist/` with any static web server. No build or dependency installation is required.

Push changes to `main` to publish automatically through GitHub Pages. The workflow publishes only `dist/`.

Forms demonstrate interactions and validation without sending or storing personal information. Before adapting for a real business, replace the fictional content with owner-approved details and connect and verify the inquiry route.
